# ProtoEvoNet
ProtoEvoNet – Open-world few-shot SAR target recognition with physics-calibrated prototype evolution.  Incremental enrolment – Add new classes from 1–10 support images, zero retraining.  Physics‑grounded – Gamma‑conditioned normalisation (GCN), Fisher‑Rao geodesics, DSAR reliability weighting.  Open‑world novelty detection
